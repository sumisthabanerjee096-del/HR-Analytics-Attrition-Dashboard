# HR Analytics Dashboard – Attrition Analysis

## Project Overview
This project analyzes employee attrition data to identify workforce trends and understand factors influencing employee turnover. SQL was used for data analysis and Power BI was used to create an interactive dashboard.

## Tools Used
- SQL (MySQL)
- Power BI
- Excel / CSV
- Data Cleaning

## Project Workflow
1. Data collection and cleaning
2. SQL analysis and business queries
3. Data visualization in Power BI
4. Dashboard creation and insight generation

## Key Business Questions
- What is the employee attrition rate?
- Which department has the highest attrition?
- Which job roles experience more employee exits?
- How does income affect attrition?
- How does experience influence attrition?
- What is the attrition distribution by gender?

## SQL Analysis Performed
- Total employees count
- Attrition count
- Attrition rate calculation
- Department-wise attrition
- Job role analysis
- Gender analysis
- Experience and salary analysis

## Dashboard Features
- Total Employees KPI
- Attrition Count KPI
- Attrition Rate KPI
- Attrition by Department
- Attrition by Job Role
- Attrition by Gender
- Sales Trend / Experience Trend visuals
- Interactive filters

## Key Insights
- Research & Development showed higher employee exits.
- Certain job roles experienced more attrition than others.
- Income and years at company showed relationships with employee turnover.
- Attrition patterns varied across departments and demographics.

## Project Outcome
Built an interactive HR dashboard to support HR decision making and identify employee retention trends.
